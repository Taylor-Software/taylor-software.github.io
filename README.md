# taylor-software.github.io

Source for the Taylor Software studio website, served at
**https://taylor-software.github.io/** via GitHub Pages (deploy from `main`, root).

Plain static HTML/CSS — no build step. Edit `index.html` / `styles.css` and push.

Product content is sourced from the org repos:
[juice](https://github.com/Taylor-Software/juice),
[deep_iq_v2](https://github.com/Taylor-Software/deep_iq_v2),
[flops](https://github.com/Taylor-Software/flops),
[homo](https://github.com/Taylor-Software/homo),
and the engineering repos (idle-engine, flutter_windows_iap, flutter_steam_iap, sfx-studio).
