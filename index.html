Deep IQ

macOS live · iOS/Android in review

Solo Magic: The Gathering opponent simulator

A dice-driven virtual MtG opponent running 14 historical and modern Deep IQ rule sets (1996 → 2026), with an in-app rule-set editor and JSON import/export.
